此技能指导创建独特的、生产级前端界面，避免通用的"AI 废话"美学。实现具有卓越审美细节和创意选择的真正工作代码。

用户提供前端需求：要构建的组件、页面、应用程序或界面。他们可能包含关于目的、受众或技术约束的上下文。

## 设计思维

在编码之前，理解上下文并承诺一个**大胆**的美学方向：
- **目的**：这个界面解决什么问题？谁使用它？
- **基调**：选择一个极端：极简粗野、极繁混沌、复古未来、有机/自然、奢华/精致、俏皮/玩具风、编辑/杂志风、粗野主义/原始、装饰艺术/几何、柔和/粉彩、工业/实用主义等。有很多风格可选。使用这些作为灵感，但设计一个忠于美学方向的。
- **约束**：技术要求（框架、性能、可访问性）。
- **差异化**：什么使这个**难以忘怀**？人们会记住的一件事是什么？

**关键**：选择一个清晰的概念方向并精确执行。大胆的极繁主义和精致的极简主义都有效——关键是意图性，而不是强度。

然后实现工作代码（HTML/CSS/JS、React、Vue 等）：
- 生产级且功能正常
- 视觉上引人注目且令人难忘
- 具有清晰美学观点的连贯性
- 在每个细节上精心打磨

## 前端美学指南

关注：
- **排版**：选择美丽、独特、有趣的字体。避免像 Arial 和 Inter 这样的通用字体；选择能提升前端美学的独特选择；意想不到的、有个性的字体选择。将独特的展示字体与精致的正文字体搭配。
- **颜色与主题**：承诺一个连贯的美学。使用 CSS 变量保持一致性。具有鲜明强调色的主导色彩优于胆怯的、均匀分布的调色板。
- **动效**：使用动画进行效果和微交互。对于 HTML 优先使用纯 CSS 解决方案。当 Motion 库可用时用于 React。关注高影响时刻：一个精心编排的页面加载配合错开显示（animation-delay）比分散的微交互创造更多愉悦。使用滚动触发和悬停状态来制造惊喜。
- **空间构图**：意想不到的布局。不对称。重叠。对角线流动。打破网格的元素。慷慨的负空间或受控的密度。
- **背景与视觉细节**：创造氛围和深度，而不是默认使用纯色。添加与整体美学匹配的上下文效果和纹理。应用创意形式如渐变网格、噪点纹理、几何图案、分层透明度、戏剧性阴影、装饰边框、自定义光标和颗粒覆盖。

永远不要使用通用的 AI 生成美学，如过度使用的字体系列（Inter、Roboto、Arial、系统字体）、陈词滥调的配色方案（特别是白色背景上的紫色渐变）、可预测的布局和组件模式，以及缺乏上下文特定特征的千篇一律设计。

创造性地诠释并做出意想不到的选择，感觉真正为上下文而设计。没有设计应该是相同的。在浅色和深色主题、不同字体、不同美学之间变化。永远不要在多代之间趋同于常见选择（例如 Space Grotesk）。

**重要**：将实现复杂性与美学愿景匹配。极繁设计需要精心制作的代码，具有广泛的动画和效果。极简或精致的设计需要克制、精确，以及对间距、排版和微妙细节的仔细关注。优雅来自于对愿景的良好执行。
